The answer was honest, which is good; the gap is that the one feature the positioning rests on has nothing behind it on the deal you'd show.

What a stranger would notice

    MediumThe first thing on the project home is a 1,500-acre masterplan shown as one red pin on bare desert. No boundary, no parcels, no plan. For a land developer that is the picture that sets expectations.
  2. 8
    MediumThe project home lists internal bug threads as recent conversations ("Project Jurisdiction Configuration Caching Error"), and several of those summaries state the budget as $40.2M across 30 lines while the register, the database and today's answer all say $39.7M across 24. The database has not changed since November 2025, so a prospect reading the home page sees two budget totals. I did not establish when those chat summaries were written.
  3. 9
    MediumParcels and Budget open as bright white tables inside a dark app. Jarring, and the only way back to the list of artifacts is a small X in the corner; clicking "Artifacts" in the header does nothing while one is open.
  4. 10
    MediumThe budget register carries three rows of filter chips and twelve column toggles above the first number, the rows are not in phase order (1.2, 4.2, 1.1, 4.1, 2.1 …), and the Phase and Assigned-To columns show the same value twice.
  5. 11
    LowSmall things: the header sat on "Loading project…" for a beat after the page had loaded; the sidebar's project list reshuffled after I opened Peoria (it dropped off the list it had just been on).

What worked

  1. 12
    WorkedThe parcel table edits in place (double-click a cell, type). The Documents panel has a sensible folder structure. Period toggles (monthly / quarterly / annual) are on the cash flow as directed on Sept 29.
